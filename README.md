# amna.yahia ✦ portfolio

> just a girl who builds any UI you can imagine.

The personal portfolio of **Amna Yahia** — frontend engineer on AI platforms (React, Next.js, TypeScript).
Maximalist by design: cheetah print, zebra stripes, hot pink, handwritten notes, and a cheetah-print scrollbar.
No templates were harmed.

## Stack

- **Next.js 15** (App Router) + **React 19** + **TypeScript**
- Hand-written CSS — custom properties, SVG pattern tiles, scroll-snap full-screen slides
- Fonts via `next/font`: Shrikhand, Fraunces, Karla, Caveat

## Highlights

- Full-screen snap slides with left/right entrance animations that replay on every visit
- Fanned card-deck project carousel (desktop) / swipe row (mobile)
- Scroll-scrubbed marquee, scroll-filled statement text, parallax photo
- Custom everything: scrollbar, cursor, text selection, progress bar, 404-energy

## Run it

```bash
pnpm install
pnpm dev
```

Then open http://localhost:3000.

## Deploy

Push to `main` and import the repo in [Vercel](https://vercel.com/new) — zero config needed.
